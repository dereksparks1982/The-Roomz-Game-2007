# Roomz-Game-2007

Preservation and reconstruction research for **The Roomz (2007)** browser puzzle game.

## Current preservation status

This tree intentionally contains **only authentic recovered game/site binaries plus research notes**. Earlier experimental reconstructed Room 4/5 material is deliberately excluded.

### Recovered original pieces

- Surviving Rooms 1-3 demo
- `RoomzMain` original loader, 2007 version
- `RoomzMain` later loader, 2011 version
- `RRR.swf`
- `UnderTR.swf`
- `data.swf`

### Critical missing pieces

- `loadRoom.swf`
- `Intro.swf`
- `frame.swf`

The missing loader payloads are the current bottleneck to restoring the original modular game beyond the surviving demo.

See `research/` for dependency analysis, provenance, archive targets, and the missing-pieces list.
