The very recent idea is to make TheRoomz IRC channel.
It will let us talk more globally.

The channel is:
#TheRoomz (letter size matters)
server: irc.quakenet.org
port: 6667-6669
group: Quakenet

1) The only thing you need is a program like mIRC.
(It's FREE so you don't have to pay for it! You can use the trial version as long as u want!)

2) If you don't know how to add server to mIRC, click HERE.

3) Important thing is registering your nick with Q - it means to authenticate it, so that other users won't take it from you. It's known as a AUTH command. It also allows me to register you as a #TheRoomz channel user to #TheRoomz users list.
To learn how to register your nick with Q (AUTH yourself) - click HERE

4) If you are AUTHed (and only in this case) you can have AUTO AUTH function. All you have to do is to open Script Editor in your mIRC window (ALT+R to open it) and paste this code:
Code:
on 1:CONNECT:{
  if (quakenet isin $server) {
    /timer-a 1 2 /msg Q@CServe.quakenet.org AUTH username password
    /echo AUTH sent.
  }
}

Replace username with your nick on the IRC and password with your password.
